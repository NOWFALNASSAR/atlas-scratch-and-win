Prizes

Changes save instantly. Picture shows on the scratch card. "Stock item" links a gift to stock: a branch only gives that prize while it has free stock. Higher "Weight" = higher chance. "Limit" = maximum per branch per day (0 = unlimited).

Chance % by bill amount

Make one column for each bill amount slab (e.g. ₹1,000–₹4,999, ₹5,000 and above) and type the % chance of each prize in that slab. Each column should total 100%. If a prize is out of stock or over its daily limit, its % is shared among the other prizes in that slab. When no slabs are set, the "Weight" column above is used instead.

Branches

Give each branch a different 6-digit PIN, and share it only with that branch manager. To change a PIN, type the new one and Save; the old PIN stops working immediately.
