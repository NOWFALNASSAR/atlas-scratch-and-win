Printer

Printer setup

Windows PC: install the thermal printer's driver, set paper size to 80 mm (or 58 mm), and make it the default printer. In the print window choose that printer, Margins: None, and untick "Headers and footers".

Android tablet: install a print-service app for your printer (for example RawBT for Bluetooth/USB thermal printers), enable it in Settings → Printing, then use the Print buttons here.
